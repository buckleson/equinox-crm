# Sterlitee CRM

Sales CRM / ERP for **Sterlitee Regal Park** ([sterliteeregalpark.in](https://sterliteeregalpark.in/)), an Indian real estate development. It manages channel partners, customers (leads), and deals (unit bookings) in INR.
